# Artwork credits

`card.png`, `icon.png` and `marketplace.png` combine three icons from SVG Repo.
`marketplace.png` is the square upload for the marketplace listing only; the
README shows `card.png`. The project code is
MIT, the artwork keeps the licences below.

| Icon | Source | Licence | Author |
| --- | --- | --- | --- |
| 3d printer | https://www.svgrepo.com/svg/19622/3d-printer | CC0 | SVG Repo |
| wrench | https://www.svgrepo.com/svg/492002/wrench-13 | CC Attribution | Lugine Hiary |
| clock | https://www.svgrepo.com/svg/434037/clock | Public Domain | Sensa |

The wrench is the one that requires attribution: name Lugine Hiary wherever the
artwork is shown. The other two do not require it, and are credited anyway.

All three images carry the credit line in their corner, which names the icon
numbers. The wrench is CC Attribution, so add `wrench by Lugine Hiary` to that
line before uploading, or rely on this file and the README table to carry it.

## Files

```
marketplace.png        2048x2048  the upload, lossless, 481 KB
marketplace-1024.png   1024x1024  the same, if a smaller one is wanted, 178 KB
card.png               2741x1530  README banner
icon.png                512x512   the mark alone
```

The marketplace takes 5 MB, so the 2048 PNG fits with room to spare. JPEG was
not used: on flat dark areas the text and edges pick up artefacts, while PNG
stays exact at this size.
